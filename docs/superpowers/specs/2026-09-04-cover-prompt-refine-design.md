# 封面提示词「修改建议」设计

## 目标

在封面图提示词弹窗中，每一套封面方案都能填写修改建议，点击「根据建议优化」后由 AI 原地改写当前 `gptPrompt`（可微调 `overlayText`），再复制去 GPT 生图。

## 交互

- 每张方案卡片内增加「修改建议」多行输入。
- 按钮「根据建议优化」：建议为空时禁用；请求中显示加载态，仅该套方案可优化，其它方案仍可用。
- 成功后替换该套 `gptPrompt`（若返回 `overlayText` 则同步更新短文案展示），toast 提示「已按建议优化提示词」。
- 「复制提示词 / 去 GPT 生图」继续使用优化后的文本。

## 接口

`POST /api/ai/cover/refine`

请求：`gptPrompt`、`suggestion`、可选 `styleLabel` / `overlayText` / `title`、`llm`  
响应：`{ gptPrompt, overlayText? }`

规则：保留 2.35:1、简体中文、安全区与原风格意图；落实用户建议，不虚构文章未支持的产品效果。

## 范围

仅封面弹窗。配图与小红书图片提示词后续复用同一模式。
