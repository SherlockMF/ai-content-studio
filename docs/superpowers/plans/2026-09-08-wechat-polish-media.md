# 公众号润色标记与自动配图

要求：首次出稿生成真实封面及正文配图；润色后只替换不匹配的图，缺图则补齐；已润色稿件显示持久标记。

1. 复用已持久化的 ai_rewrite 历史，在列表与编辑区显示标记，普通编辑不清除。
2. 新增内部 POST /api/ai/wechat/media-plan，接受新正文、原正文与现有 LLM 设置。以原图的提示词、标题及上下文判断是否匹配；返回受校验的图位方案，不允许模型编造原图 URL。
3. 客户端共享配图执行器复用 /api/ai/image/generate，使用现有生图设置，先保存文字及图位，再逐张持久化图片；保留匹配的 URL，失败图位可重试。
4. 接入选题首次出稿、稿件润色和旧稿补图入口。防止异步配图覆盖用户在期间的修改。
5. 验证历史标记、保留/替换策略、部分失败、图片位置及 UI。真实模型调用仅在现有稿件补图范围内使用。
