# 小红书发布包与角标一致性

目标：发布包包含真实图片与可复制文案，整组生成图统一不画页码角标。

方案：复用 JSZip，在 publish.ts 中按 imagePlan.index 导出 images/ 下的原图，根目录提供标题、正文、标签、完整笔记，备选文案放单独目录。保留 Markdown 概览，但图片链接改为包内相对路径。缺图、空图片、非图片响应和下载失败阻止导出，不静默漏图。React 按钮显示导出状态并阻止重复点击。

角标规则：规划、渲染及复制提示词共用一条禁止页码/角标的规则，明确覆盖旧提示词中的页码要求；正文内的事实数字与步骤编号不受影响。旧图片不自动修改，需要重新生成。

1. 为 ZIP 内容、图片顺序、缺图和下载失败补测试，确认旧实现失败。
2. 实现 ZIP 并接入发布面板；按当前选中文案导出，保留备选版本。
3. 为角标规则补测试并接入规划、渲染和复制路径。
4. 运行相关测试、ESLint、类型检查；报告未验证的真实生图效果。
